# Open Source Attribution

QueryPilot uses components of the open-source isometric city-building engine originally developed by **amilich** under the MIT License:

- Original Repository: [amilich/isometric-city](https://github.com/amilich/isometric-city)
- Original Author: amilich
- License: MIT License (see `LICENSE`)

The canvas isometric projection mathematics, depth sorting, tile rendering pipeline, and road connectivity algorithms have been adapted and repurposed to visualize database schemas, entity-relationship topologies, and multi-agent AI data investigations.
